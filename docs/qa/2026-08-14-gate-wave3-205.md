### ⚠️ Coverage gap found (non-blocking, flag for backlog)
`_find_violations()` in the guard test only checks **presence** of the `encoding=`/`errors=` kwargs (`missing = [kw for kw in ("encoding","errors") if kw not in kwarg_names]`) — it never inspects the **value**. A call site with `encoding="utf-8", errors="strict"` passes the guard silently, even though the guard's own docstring says `errors="strict"` is exactly the case that "still raises the same way" and must never be used. This means a future regression that sets `errors="strict"` (or any value other than `"replace"`) on a text-mode call would **not** be caught by this test.

Not blocking this gate because:
- No current call site in `src/agent_takkub/` uses `errors="strict"` (grepped, none found) — the 23 fixed sites all use `"replace"`.
- The guard still catches the primary failure mode (missing kwarg entirely), which is what actually crashed pid 19952.

Recommend a follow-up ticket to tighten `_find_violations()` to also assert `errors` literal `== "replace"`.

## 3. Real reproduction of the crash (cp874, byte 0x9a)

This QA machine's actual `locale.getpreferredencoding()` **is `cp874`** (genuinely Thai-locale Windows), so a live repro was possible without simulation:

- Child script `poison_child.py` writes `b"hello \x9a world\n"` to stdout (`0x9a` confirmed undefined in cp874 via `bytes([0x9a]).decode('cp874')`).
- **BEFORE** (`text=True`, no `encoding=`): reproduced the *exact* real failure — `Exception in thread Thread-1 (_readerthread)`, `subprocess.py:1597`, `encodings\cp874.py:23`, `UnicodeDecodeError: 'charmap' codec can't decode byte 0x9a` — matching the real pid 19952 traceback verbatim. The exception is uncaught in the *main* thread (dies in the reader thread), so `subprocess.run()` returns with `stdout=None` instead of raising where a caller could catch it — this is why it silently kills output rather than surfacing as a catchable exception.
- **AFTER** (`encoding="utf-8", errors="replace"`): no crash, decode succeeds, output contains `U+FFFD` replacement character in place of the unmappable byte.

Full harness: `poison_child.py` + `repro_205.py` in scratchpad (not committed, throwaway).

**This is real end-to-end proof, not simulation** — same machine, same locale, same byte, same traceback as the production bug.
