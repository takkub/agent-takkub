# Graft Final Role

Keep Graft.

Graft = structural code intelligence:
- symbols
- references
- call relationships
- signatures
- code structure

Do not replace it with OpenViking.

Example:
```text
"ทำไมเลือก Redis?"       -> Brain/OpenViking
"RedisClient เรียกที่ไหน" -> Graft
```

Graft may be queried as a tool/context source, but its graph remains specialized.
