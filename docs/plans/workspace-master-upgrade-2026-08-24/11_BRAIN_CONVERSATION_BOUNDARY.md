# Brain / Conversation Boundary

Conversation V2 owns:
- session lifecycle
- message state
- rolling summary
- checkpoint/resume

Brain V2 owns:
- operational learnings
- decisions
- project facts
- user/project preferences
- trust/confidence/scope/provenance

Do not put raw project docs into Brain simply because they exist.
Do not duplicate whole conversations into Brain.

Context Builder queries both according to task.
