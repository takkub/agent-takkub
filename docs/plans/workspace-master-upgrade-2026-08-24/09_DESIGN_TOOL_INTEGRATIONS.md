# Design Tool Integrations

All integrations live behind Capability Hub + PermissionEngine.

## Storybook
Priority 1 when project has it.
Use existing production components before creating new components.

## 21st.dev
Real client/MCP integration to add:
- search components/templates
- retrieve references/variants
- record provenance
- never blindly copy whole unrelated design systems

## Figma
Optional:
- variables
- components
- frame/design context
- design-to-code handoff
- Code Connect mapping where available

## Penpot
Optional open-source/self-hosted alternative.

## Policy
Designer chooses sources:
1. existing project Storybook/design system
2. project docs/Obsidian/OpenViking
3. 21st references
4. Figma/Penpot if configured

External content is untrusted until reviewed.
