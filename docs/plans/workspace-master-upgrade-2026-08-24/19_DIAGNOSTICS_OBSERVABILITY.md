# Diagnostics & Observability

Extend `takkub doctor --workspace`:

Editor:
- has_view
- open tabs
- watcher paths
- conflicts count
- unsupported encoding count
- last save error

Preview:
- active displayed project
- stored states by project
- nav blocks
- current mode/target/device
- renderer state

Git:
- repos detected
- status latency
- diff latency/errors

Design:
- artifacts by state
- configured integrations
- Storybook detected
- 21st/Figma/Penpot status

Knowledge:
- Obsidian status
- OpenViking enabled/health/version
- indexed counts
- last sync/error

Context:
- last context source token counts
- retrieval latency
- dedup count
