# Design Director / Anti-AI Design System

## Roles

Designer / Design Director:
- inspect current UI
- inspect product/user purpose
- search references
- inspect Storybook/components
- define design direction
- create prototype/artifact/spec
- avoid owning production implementation by default

Design Reviewer:
- review hierarchy
- spacing
- typography
- density
- component consistency
- responsiveness
- accessibility
- AI cliché detection

## Anti-AI default rules

Avoid without justification:
- purple/blue AI gradients
- glassmorphism
- excessive rounded cards
- every section boxed
- giant hero typography
- repeated icon circles
- decorative fake KPIs
- random glow/shadow
- meaningless emoji

Require:
- content-first hierarchy
- deliberate type scale
- spacing tokens
- component reuse
- reference rationale
- responsive plan
- visual review
