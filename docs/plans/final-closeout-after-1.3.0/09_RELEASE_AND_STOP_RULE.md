# Release / Stop Rule

Suggested:
- immediate bug-only fix (#376 etc.) -> patch release
- Settings UI + strict OpenViking scope + Context Debug -> next minor release

After these are complete:

STOP adding major architecture to 1.x.

Use the system on real projects.
Collect:
- bugs
- token usage
- context relevance
- provider failure rates
- retrieval latency
- agent rework rate

Only start Phase 10 / 2.0.0 when its own prerequisites are satisfied.
