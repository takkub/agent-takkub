# Target UX

```text
Install Takkub
→ Open Cockpit
→ Settings > OpenViking
→ [Install & Enable]
→ one-time provider/model setup
→ Takkub installs and starts local server

Next launch:
Open Cockpit
→ health check
→ start managed OpenViking automatically
→ ready

Close Cockpit
→ stop process only if this Cockpit started it
```

No Docker. No terminal. No manual service startup.
