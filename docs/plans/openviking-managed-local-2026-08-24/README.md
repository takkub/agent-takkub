# Takkub OpenViking Managed Local Plan

Target: current `takkub/agent-takkub` main.
Goal: OpenViking runs LOCAL only, no Docker, no manual terminal startup.

Current main already has HTTP adapter, health/search/index, fail-open behavior, and strict project scope.
This pack adds the missing managed-runtime UX: install/start/stop/restart/update/repair/settings/studio.
