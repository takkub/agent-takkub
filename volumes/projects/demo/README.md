# sandbox-demo

A tiny placeholder project so the `takkub-sim` Docker sandbox has something
to open on first boot — see
`docs/guides/2026-08-31-docker-sandbox.md`.

Ask Lead (through the PWA, or `takkub say` inside the container) to make a
change to `src/hello.py` and report back — that's the whole point of this
project: proving a Lead pane can spawn, work, and answer inside the sandbox.
